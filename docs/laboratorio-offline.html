04 — reproducirlo

Cómo lo levanté

Versión condensada. El paso a paso completo con cada archivo de configuración está en docs/entorno-local-sin-servidor-real.md.

mock de Laravel + impresora fake2 procesos
python3 mock_laravel.py &          # 127.0.0.1:8000 → resuelve 1 impresora
nc -l -k 127.0.0.1 9100 > /dev/null &  # traga bytes ESC/POS, nunca falla
servidor localusqay-print-server
go build -o server ./cmd/server
./server   # config.json: port 8080, laravel_base_url http://127.0.0.1:8000
cliente localusqay-print-client
go build -o client ./cmd/client
./client   # config.json: server_url ws://127.0.0.1:8080/ws/agent
disparar un trabajocurl
curl -X POST http://127.0.0.1:8080/api/v1/jobs \
  -H "X-Internal-Token: local-test-token" \
  -d '{"job_id":"job-1","terminal_id":"caja-local", ...}'
Documentación completa: docs/entorno-local-sin-servidor-real.md Regla del proyecto sin cambios: impresión física real solo se valida en la VM Windows — ver docs/entorno-pruebas-windows.md.
